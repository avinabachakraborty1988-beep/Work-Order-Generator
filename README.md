# Work Order Generator

A Google Apps Script web application for Indian Chain Private Limited
to generate, manage and print work orders.

## Files
- `index.html` — Frontend web form
- `code.gs` — Google Apps Script backend
- `appsscript.json` — Apps Script configuration

## Setup
1. Create a new Google Apps Script project
2. Copy code.gs and index.html into the project
3. Update the constants (Spreadsheet ID, Folder ID) with your own values
4. Deploy as a web app
